# Defensive datasets

Authorized **defensive** security benchmark tasks (HARBOR / cyber-bench) —
source-patching and analysis/triage challenges where the agent hardens code,
fixes real vulnerabilities, or produces structured analytical findings, graded by
behavioral verifiers.

> **Status:** no defensive datasets have been published in this repository yet.
> This section is reserved so the offensive and defensive suites sit side by side
> as the collection grows.

When populated, each task will follow the same package layout as the
[offensive datasets](../offensive-datasets/): an agent instruction, task metadata,
a reference fix or reference analysis, a behavioral verifier, the build
environment, model evaluation runs, and an independent QC review — with a per-task
README carrying the task summary and the model evaluation table.
